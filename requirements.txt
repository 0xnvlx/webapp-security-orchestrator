# Python tooling the claude-red web/api/auth/tls skills shell out to.
# The Dockerfile installs these into an isolated venv (/opt/venv) that is put
# on PATH for every user in the image. This is the *pip layer* of the image —
# system packages (openssl, nmap, john, sslscan), the Go tool (tlsx), and the
# git-cloned tools (testssl.sh, jwt_tool) are installed by the Dockerfile itself.
#
# Heavy crypto-ATTACK tooling (RsaCtfTool, SageMath, padbuster) is intentionally
# omitted: the crypto-attacks skill is opt-in, and SageMath alone would add >1 GB.
# See the tooling table in the README ("Without Docker").
#
# Lower bounds, not exact pins, so the image keeps building as upstreams move.
# Pin exact versions here if you need a byte-reproducible image.
